# Assets

Coloque aqui os icones da aplicacao:

- `icon.png` — Icone principal (512x512 recomendado), usado na janela e tray
- `icon.ico` — Icone Windows (256x256), usado no executavel e instalador

Para gerar o .ico a partir de um .png, use:
- https://www.icoconvert.com/
- Ou `npm install --global png-to-ico && png-to-ico icon.png > icon.ico`
